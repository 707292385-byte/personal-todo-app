# 个人待办应用 · 独立部署版

一套部署 = 一个人的专属实例。数据存在各自的部署环境里，互不共享。

## 功能

- 口令登录（用户名 + 口令，口令至少 6 位）
- 今日清单：逾期 / 今天 / 以后 / 已完成 分组，搜索与筛选
- 桌面端（≥900px）组件看板：任务输入、任务清单、四象限、日历、专注、时间线、看板、统计
  - 组件可拖动排序、调宽度（1/4～通栏）、调高度（矮/中/高/很高）、移除、添加
- 手机端（<900px）底部五个标签页：今日、四象限、日历、专注、统计
- 中文自然语言添任务：「明天下午3点 提交报告」自动解析日期时间
- 四象限拖动改重要性与紧急程度；看板拖卡片或下拉改状态（今日待办/待办/进行中/已完成）
- 重复待办（每日/每周/每月）、专注计时、投入时段、周统计

## 在 WorkBuddy 中部署

1. 把 todo-app 文件夹放到你的 WorkBuddy 工作区（或本机任意目录）。
2. 打开 WorkBuddy，选好工作区，对助手说：「把 todo-app 发布为应用」。
3. 助手会给出一条专属链接（形如 https://xxx.app.workbuddy.host/...）。
4. 第一次打开链接会看到注册页，**注册你自己的账号**（首位注册者之后注册通道自动关闭）。
5. 手机或电脑打开链接即可使用；手机可加到主屏。

## 本地运行（可选）

```bash
cd todo-app
node server.js          # 默认 8788 端口，可用 PORT 环境变量指定
```

零依赖，不需要 npm install（Node ≥ 18）。数据写在 `data/` 目录，按用户分文件保存。

## 给别人用

- **不要**把自己的链接直接给别人——那是你的实例，数据混在一起。
- 把这份 todo-app 文件夹发给对方，对方按上面的步骤自己部署，得到自己的实例。
- 分发前确认没有 `data/` 目录：`data/` 里是你自己的账号与任务数据，以及 secret.key。

## 注意

- 换实例 = 换数据，两个实例之间不会同步。
- 注册通道只开放给首位使用者，第二人无法注册（这是刻意设计，保证一人一实例）。
- 备份：直接复制整个 `data/` 目录即可。
